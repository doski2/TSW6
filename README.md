Control automático de velocidad y calibración de perfiles para Train Sim World 6.

**Requisitos:** TSW6 + **UE4SS** (`TelemetryProbeMod`) para telemetría rápida; **`-HTTPAPI`** además
para autopiloto (escritura de mandos). Python 3.9+, en cabina.
